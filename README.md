# Radar Opus

A modern web successor to desktop homeopathic repertorisation software: repertory, materia medica, case management and analysis in one keyboard-first workspace.

## Data and licence

Repertory and materia medica data comes from [OOREP](https://github.com/nondeterministic/oorep) and is licensed GPL v3, so this project is GPL v3 as well (see `LICENSE`).
